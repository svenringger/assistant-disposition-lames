# Exemple

Mur fictif, pour voir le calcul et la page sans saisir tes propres cotes.

- `entree.json`: largeur, hauteur, lames et une ouverture d'exemple
- `disposition.html`: ouvre ce fichier dans un navigateur

Pour régénérer la page, depuis la racine du dépôt:

```text
node tools/calepinage_v1.cjs page exemple/entree.json --sortie exemple/disposition.html --variante 1
```
